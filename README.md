# Veylo desktop releases

Installers and update files for the Veylo desktop app (Windows, macOS and Linux).

This repository only hosts release files. It contains no source code.

- **Download the latest version:** from the Veylo website, https://veylo-chat-app.onrender.com
- **Older versions:** see [Releases](../../releases)
- **Updates:** the desktop app checks here and updates itself
